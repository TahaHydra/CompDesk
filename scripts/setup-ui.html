Where do I find the setup token?

It is printed only in the trusted CompDesk process or container logs. The browser never receives it automatically.

Release Docker Compose

docker compose logs --tail=50 compdesk

Docker Compose built from this source repository

docker compose -f docker-compose.yml -f docker-compose.build.yml logs --tail=50 compdesk

The token is used only to authorize first-time setup and expires after 30 minutes. If it expired, restart the CompDesk container or local setup process to generate one new token, then check the logs again.
