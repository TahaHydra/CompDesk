# CompDesk v0.9.0-beta.1

The first public beta of CompDesk, a lightweight, privacy-first, self-hosted help desk built by xHydra.

## Highlights

- Docker-based deployment
- Secure first-run setup
- Ticket creation and lifecycle management
- Multiple assignees
- Roles and permissions
- Attachments
- Search and filtering
- Customizable organization branding
- SMTP configuration
- Backup and recovery documentation
- Security-focused CI and container scanning

## Beta notice

This is the first public beta. It is intended for evaluation, testing and early deployments.

Before production use:

- review the configuration;
- configure backups;
- test email delivery;
- verify reverse proxy and TLS settings;
- test restoration procedures;
- review security documentation.

Please report bugs and feature requests through GitHub Issues.
