# CompDesk v0.9.0-beta.7 — Public Beta (draft)

Saved replies: agents and administrators can keep their own reply snippets and insert them while answering a ticket.

## New: saved replies

- **In the reply box,** a **Saved replies** button sits next to Public reply / Internal note. It lists your replies, most used first, with a search box that matches titles and text. Use the arrow keys and Enter, or click: the text is inserted where your cursor is. Your draft is never replaced and nothing is sent until you press Send.
- **Save current reply** stores what you've typed under a title you choose.
- **My Profile → My saved replies** lets you create, edit, rename and delete them.
- **Personal and staff-only.** Only you can see or use your saved replies; administrators cannot see other people's. Requesters do not have the feature. Each person can keep up to 200.
- **Existing canned responses keep working.** Installations that already had shared canned responses see them read-only under **Shared responses** in the same menu. `/api/canned-responses` is unchanged.

## API changes

- New endpoints: `GET/POST /api/saved-replies`, `PATCH/DELETE /api/saved-replies/{id}`, `POST /api/saved-replies/{id}/use`. See the [API reference](../API_REFERENCE.md#saved-replies).

## Upgrade and rollback

This release adds one table, `saved_replies`, through an additive migration that runs automatically on start; no existing table changes. Back up PostgreSQL, private attachments, uploaded branding and the configuration volume together, then:

```sh
docker compose pull
docker compose up -d
docker compose logs --tail=100 compdesk
```

Rolling back to beta.6 works with the upgraded database: beta.6 ignores the extra table. Saved replies created in beta.7 reappear if you upgrade again.

## Verification

- Lint, type checking and the full Jest suite pass, including new tests for staff-only access, per-user scoping (another user's reply is "not found"), the 200-reply limit, input limits, audit entries without content, and inserting at the cursor.

- The demo dataset gives the IT agent two saved replies; the demo lifecycle test checks they are installed and removed with the demo accounts.
