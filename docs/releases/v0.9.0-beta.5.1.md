# CompDesk v0.9.0-beta.5.1 — Public Beta

A small update to beta.5: choosing where a tag is available now scales to many departments and categories, and the notifications panel reads properly on computers and phones. There are no database or configuration changes.

## Improvements

- **Tag availability editor.** Under **Admin → Tags**, "Selected departments" now uses two searchable lists instead of a checkbox per category. **Departments** picks one or more departments. **Categories** (optional) lists the categories of the chosen departments under a heading for each department, and you can pick several. A department with no category picked covers all of its categories. A summary underneath shows exactly where the tag will be available. Both lists open in place, so search, keyboard use and Escape work inside the dialog, and they stay usable on a phone with long lists.
- **Notifications panel.** Long ticket titles and comments are now shortened with "…" instead of being cut off at the panel edge, and the panel keeps a margin from the screen edges on phones. Each item starts with what happened ("Ticket created", "New comment", a status change), followed by the ticket, and the panel shows how many items are unread, with a marker on each one. A newly created ticket no longer repeats its title twice.
- **Tag picker.** The tag buttons no longer show a count that could disagree with the tags shown beside them, and on touch screens opening the list no longer raises the keyboard over it.

Tag changes are not sent as notifications: tags are triage labels that requesters often cannot see, and changes are recorded in the audit log.

## Upgrade and rollback

There are no database migrations in this release. Back up PostgreSQL, private attachments, uploaded branding, and the private configuration volume together. Download this release's version-pinned `docker-compose.yml`, review it against your deployment configuration, then run from the deployment directory:

```sh
docker compose pull
docker compose up -d
docker compose logs --tail=100 compdesk
```

If you deploy with your own Compose file, change only the image tag to `ghcr.io/tahahydra/compdesk:0.9.0-beta.5.1` and confirm the persistent paths `/config`, `/app/public/uploads` and `/app/storage/attachments` are mounted.

Rolling back to beta.5 needs only the beta.5 image; the database and configuration are unchanged. See [upgrade guidance](https://github.com/TahaHydra/CompDesk/blob/v0.9.0-beta.5.1/docs/UPGRADING.md) and [backup/restore](https://github.com/TahaHydra/CompDesk/blob/v0.9.0-beta.5.1/docs/BACKUP_AND_RESTORE.md).

The notifications panel, ticket list and ticket tag editor were checked at both sizes.
- The beta.4.2 → beta.5 update was rehearsed end to end with the published images, following the in-app update instructions; data, settings and sign-in sessions were preserved.

This is a public beta; the [beta.4 limitations](v0.9.0-beta.4.md#verification-and-beta-limits) still apply.
