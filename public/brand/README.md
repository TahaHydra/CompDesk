# xHydra brand marks

Source assets for the xHydra creator attribution used throughout CompDesk.

- `xhydra-mark-black.png` — 256×256, transparent background. Use on light backgrounds.
- `xhydra-mark-white.png` — 256×256, transparent background. Use on dark backgrounds.
- `xhydra-app-icon.png` — 1024×1024, opaque `#f3f1ec` background. Source for favicon, PWA icons, and the Open Graph/social preview image.

Do not stretch, recolor, or distort these marks. Regenerate the derived favicon/manifest/OG assets with:

```bash
node scripts/generate-brand-assets.mjs
```
